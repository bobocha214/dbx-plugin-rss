# 收藏、批注与专注阅读设计

## 目标与边界

延续 Go Sidecar、原生前端、本机 JSON 存储和 Apache-2.0。插件 ID 保持 io.github.yuzhi.rss；不增加同步或外部 AI 服务。本设计中的“处理句子”指选取、复制、划线、高亮、文字着色和关联笔记，不包含改写订阅原文或自动翻译。

## 技术选择

推荐扩展现有 state.json，以独立收藏快照和引用式批注实现，沿用现有原子保存和读写锁，避免引入新的数据库和编辑器依赖。另一方案是引入 SQLite 与完整富文本编辑器，适合未来大型资料库，但会增加当前版本的迁移与部署复杂度。直接修改文章 HTML 虽然简单，但刷新会覆盖编辑，且难以保持安全清洗，不采用。

## 收藏与分类

- 文章列表和阅读器均提供收藏/取消收藏入口。侧栏新增“我的收藏”，支持分类筛选和搜索。
- 收藏分类独立于订阅分组，支持创建、重命名和删除；单篇收藏归属一个分类，默认“未分类”。删除分类将收藏移到未分类。
- 收藏保存文章内容、来源名称、原文地址、原 feedId/articleId、收藏时间和分类 ID。来源刷新时更新关联快照但保留分类与收藏时间。
- 删除订阅或应用文章保留上限时保留收藏快照，取消收藏后不自动删除关联笔记。

## 笔记与文字标记

- 阅读器提供“文章笔记”面板，可新增、修改和删除多条整篇笔记。
- 选中同一篇正文中的文字，显示选择工具条：复制、黄色/绿色/蓝色/粉色背景高亮、红/蓝文字颜色、下划线、添加批注。笔记按纯文字保存，不执行输入 HTML。
- 同一选区保存一种背景/字体色和下划线状态，可在标记管理面板更新或删除；重叠选区在首次实现中提示先编辑已有标记，避免混乱叠加。
- 标记记录正文纯文字偏移、选中文字、前后上下文和显示模式。通过 DOM 文本节点映射渲染 mark/span，仅由内部安全属性设置颜色。
- 重开文章优先校验偏移对应的原句，再以原句及上下文唯一定位；重复句子不能唯一定位或正文/显示模式变化导致失配时不错误上色，在笔记面板显示“原句位置已变化”，保留摘录和笔记。
- 首次添加笔记保存文章参考快照，即使订阅被删除或文章过期仍能在“我的笔记”查看和阅读。笔记与收藏快照通过 feedId/articleId 关联，避免依赖分页加载内容。
- 全局“我的笔记”支持按文章/关键词查找，显示摘录、笔记、颜色与修改时间，点击定位到关联文章和标记。

## 专注阅读与护眼

- “专注阅读”隐藏订阅和文章列表，正文在插件可用区域内居中放大；保留退出按钮，Esc 优先关闭弹窗，其次退出专注阅读。
- 提供字号 14–28px、行距 1.5–2.4、正文宽度 600–1200px。窄窗口以实际可用宽度为上限。
- 主题可选跟随 DBX、浅色、深色、暖纸色、柔和绿；后两项作为护眼配色，不宣称医学防护或修改系统屏幕设置。
- 设置持久化；正文主题、高亮颜色和文字颜色在各主题下保持可辨。焦点、键盘操作与窄窗口退出入口可用。

## 存储与接口

state.json 新增 collectionCategories、savedArticles、annotations 和 articleNotes 数组。旧文件缺失字段初始化为空，现有订阅/分组/阅读记录保留；新增阅读设置通过默认值兼容旧设置。写入失败回滚内存并显示错误。

Go 新增 collections.go、annotations.go，分别负责分类/收藏与快照/文字标记/笔记。RPC 增加分类管理、收藏切换与查询、笔记/标记增删改查和独立文章快照读取。所有写入校验文章标识、分类归属、颜色枚举、笔记长度和选区上下文；快照只从已有本地文章复制，不能由 UI 写入任意 HTML。删除订阅和文章清理不影响独立资料。

前端将收藏/笔记管理、选区与锚点渲染拆成独立模块，阅读器保留统一安全清洗流程。弹窗使用实际 DOM，不使用 DBX 沙箱不支持的 window.prompt 或原生表单提交。

## 验收

验证收藏分类 CRUD、重启持久化、订阅删除后收藏/笔记可读、取消收藏不误删笔记、选区跨文本节点、重复句定位、刷新后失配提示、恶意笔记/颜色输入拒绝、存储失败回滚。实际开发宿主检查收藏/批注/文字着色、退出专注阅读、护眼主题和窄窗口布局。执行 Go tests/vet、前端测试及实际页面验证，更新至 0.3.0 后打包 Windows x64。
